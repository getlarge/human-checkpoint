Why two touches during setup?

The first creates public enrollment material. MoltNet then returns a server-owned registration challenge; the second touch binds that exact registration.

Technical setup details

The browser keeps the MoltNet session in an HttpOnly cookie and contacts the signer companion only over loopback. ARKG seed public material is registered with the team; private signing operations remain on the YubiKey.

Honest limitation

previewSign is a Yubico firmware-preview extension. A 5.8 version string alone is not enough; the device must advertise the capability.
